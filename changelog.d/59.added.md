**TikTok streaming egress.** OBS can now push to TikTok, whose ingest has no built-in OBS service and whose RTMP URL + key are minted per session (via the Streamlabs TikTok API): a new `tiktok` case streams as a raw `rtmp_custom` target, and both the server URL and key ride in the `obs-tiktok-stream-key` secret. Enabled on stage-1 (`obs_streaming`), alongside the existing 9:16 vertical scene.
